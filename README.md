## 主题简介
**Fortudog** 是一款面向 [Typecho](https://typecho.org/) 博客系统的轻量级主题，整体采用毛玻璃（Glassmorphism）视觉风格，界面简洁大方、层级清晰。主题内置封面语录、侧边栏头像/统计/搜索、文章缩略图自动提取、评论区一体化样式等能力，开箱即用，适合个人博客、作品集、日记类站点。
**接触建站较晚**，*大概2024年才知道typecho，一见面就深深爱上了博客搭建，在这上面可以最简单的展示出自己写的东西，于是想要自己开发一款主题。可由于没深入学习过相关代码知识，自己摸索难度太高，写了一半便想放弃了，最近AI越来越生猛，这才想起两年前留下的半成品，便请教AI老师完成了这款主题。*

## 安装方法
1. 下载本主题压缩包，上传至themes文件夹，解压。
2. 登录 Typecho 后台 → **控制台 → 外观 → 可用的主题**，找到 **Fortudog** 并点击「启用」。
3. 进入「设置外观」可查看主题说明卡片（当前版本暂未提供可视化样式配置）。
